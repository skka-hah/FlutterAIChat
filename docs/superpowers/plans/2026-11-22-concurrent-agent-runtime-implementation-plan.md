# 多会话并发与 Agent 运行时实施计划

目标是在同一个应用进程里同时推进多个会话。首版默认允许两个执行占用额度，每个会话保留一个活跃主 turn，进程重启后恢复历史和可继续处理的交互。设计与验收依据见[设计草案](../specs/2026-11-22-concurrent-agent-runtime-design.md)。

## 1. 调度与会话隔离

- [x] 在 `AgentRunManager` 中实现同步占用、FIFO 调度、独立 `runId`、定向取消以及挂起和恢复。调度测试以受控异步任务验证实际重叠和容量释放。
- [x] 给 `ChatSessionCoordinator` 的选择、草稿初始化、历史读取和分页加上选择归属校验。覆盖 A → B、A → B → A，以及旧分页晚到的情况。经数据库等待后，只有归属于当前选择的结果可以更新 UI。
- [x] 发送、排队和恢复入口捕获目标会话、运行时配置和用户提示。工具按目标会话解析工作区。草稿持久化前通过草稿对象占用，取得 `groupId` 后转交调度器。同会话维持 Steer 和 Queue 消费时机。
- [x] timeline、发送 phase、reasoning draft 和 preview 按会话归属写入。预览回调校验 `runId`，各会话独立串行提交。会话切换读取对应投影，保留 final takeover、分页及交互卡。

## 2. 接通应用级运行生命周期

- [x] 在 Riverpod 根容器挂载 `AgentRunManager`。会话在异步工作前占用，实际执行取得额度后才启动 `TurnHarness`。输入区和时间线支持排队状态与定向取消。
- [x] 起始发送和两种恢复共用运行池。流订阅由执行入口持有，停止携带选中会话的目标 `runId`，清理由所属运行结算。
- [ ] 让取消信号传递到模型和支持取消的工具。执行器结算前提交已收到的部分输出。不可撤回的操作若晚到，按原 turn 记录实际结果，阻止再次进入 planner，覆盖取消后的迟到分支。
- [ ] 在隔离和定向停止的集成测试通过后解除会话切换限制。删除活跃会话前结算目标运行与内存队列，并校验结算回调无法重新写入已删除会话。摘要与标题更新使用运行归属的会话。

## 3. 接通审批、回答与进程恢复

- [x] 确认、拒绝和回答按持久化的 `groupId`、`turnId`、工具调用 ID 与等待状态校验。重复操作只处理一次。挂起时释放额度，恢复时沿用 transcript 并分配新的 `runId`。队列在等待期间归属原会话，主 turn 终止后消费。
- [x] 在 bootstrap 就绪前通过 `ChatStorage` 恢复等待中的 turn，并将遗留的运行中 turn 收敛为中断。测试覆盖恢复幂等性和已写入 transcript 的保留。

## 4. 首版验收

- [x] 使用受控模型流和真实 `TurnHarness`、事件仓库及投影验证 A 未结束前 B 发起模型调用、切回 A 可见预览、停止 A 后 B 继续，以及排队取消。
- [ ] 覆盖 A 等待审批或回答时 B 正常结束、恢复请求重复提交、同会话快速双发、池满取消排队、取消期间迟到事件和进程重启。验证原有 Steer、Queue、流式 takeover 和交互恢复回归。
- [ ] 用 Flutter 3.35.7 跑相关测试和静态分析。用 `assets/debug/test_cases.json` 记录需要保留的手测场景，并优先依仓库脚本在 Android 真机验证会话切换、定向停止和审批。日志核对 `groupId`、`turnId`、`runId` 与关键状态变化。涉及 provider 协议或请求语义时运行仓库要求的本地与上游契约测试。
- [ ] 验收后更新 `README.md` 与相关架构文档，使三种标识、取消时序、投影归属和恢复行为与实现一致。若形成新的仓库级约束，同步更新 `AGENTS.md`。

## 5. 首版验收后接入子 agent

- [ ] 增加子 turn 的持久化父子关联与显式上下文范围。子执行复用运行池，模型可见工具与实际执行权限均取角色和父会话权限的交集。
- [ ] 接入委派工具与 UI。异步委派返回子任务 ID，父收件队列按子任务 ID 去重。父等待时释放额度，父取消传播给活跃子任务。集成测试验证父子执行实际重叠、结果只交回原父 turn、终态后迟到结果无法推进父循环。

## 验收记录

- Flutter 3.35.7 的受控集成测试覆盖两个模型请求实际重叠、切回后的预览、定向停止、排队取消、跨会话回答和重复提交，以及启动恢复。
- DeepSeek Anthropic 的 9 项和 DeepSeek Chat Completions 的 3 项上游契约测试通过。MiniMax Chat Completions 出现连接写入失败。当前 Codex Responses 上游报告 `gpt-5.4` 无可用通道，相关续转场景未通过。
- 全量测试还报告 WebView 调试页超时和部分界面用例失败。修正全量运行中发现的生产入口编译错误和事件归属测试后，相关测试已复跑通过。
- 当前环境没有连接 Android 真机。复测步骤记录在 `assets/debug/test_cases.json`。
